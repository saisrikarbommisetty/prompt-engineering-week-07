# Week 07 – Advanced Prompt Engineering Using Prompt Variations

## 1. Aim

To understand how variations in prompt structure, output constraints, and role-based instructions influence the responses generated by a Large Language Model.

## 2. Objectives

- Understand different prompt variations.
- Compare basic and enhanced prompts.
- Apply sentence-count constraints.
- Use simple-English instructions to control response complexity.
- Implement role-based prompting.
- Understand the use of system messages in LLM interactions.
- Observe how prompt instructions influence response style and content.
- Implement API call limits to control usage.

## 3. Technologies Used

- **Programming Language:** Python
- **API Provider:** Groq
- **Python SDK:** OpenAI Python SDK
- **LLM Model:** llama-3.3-70b-versatile
- **API Endpoint:** Groq OpenAI-compatible API
- **Development Environment:** Google Colab
- **Secret Management:** Google Colab Secrets

## 4. Experiment Description

This experiment demonstrates how different prompt structures can influence the responses generated by an LLM.

The experiment uses William Shakespeare's *Romeo and Juliet* as the common topic and compares three different prompts.

### Prompt 1 – Basic Prompting

"Summarize about Romeo and Juliet in one paragraph."

This prompt requests a general summary of the story in paragraph format.

### Prompt 2 – Output-Constrained Prompting

"Summarize about Romeo and Juliet in exactly 2 sentences. Response should be in simple English."

This prompt introduces:
- An exact sentence-count requirement.
- A simple-English language constraint.
- A clear output structure.

### Prompt 3 – Role-Based Prompting

"Consider yourself as a romantic writer. Give information about Romeo and Juliet in 2 sentences. Response should be in simple English. Describe the forbidden love of Romeo and Juliet."

This prompt introduces:
- A romantic writer persona.
- A two-sentence constraint.
- Simple-English instructions.
- A specific content focus on forbidden love.

All three prompts are sent to the same Groq-hosted Llama model, and their responses are displayed for comparison.

## 10. Analysis

The first prompt provides a general summary of Romeo and Juliet.

The second prompt introduces specific output constraints by requesting exactly two sentences and simple English.

The third prompt further guides the model by assigning a romantic writer role and focusing on the forbidden love between the two characters.

The comparison demonstrates how prompt instructions can influence response length, language complexity, tone, and content focus.

## 11. API Usage Control

The experiment defines a maximum API call limit of 40.

The `ask_llm()` function maintains a call counter and raises an error if the maximum number of calls is exceeded.

This helps control API usage during experimentation.
